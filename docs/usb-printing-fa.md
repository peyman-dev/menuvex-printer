# چاپ USB روی همهٔ نسخه‌ها (ویندوز ۷، ویندوز، لینوکس، مک)

هدف: پرینتر حرارتی USB روی همهٔ سیستم‌ها کار کند — **بدون WebUSB، بدون تعویض درایور به WinUSB، و بدون نیاز به IP/شبکه.**

## تصمیم معماری (مهم)

روی **ویندوز** مطمئن‌ترین راه USB، «اسپولر RAW ویندوز» است: درایور USB خود پرینتر را در ویندوز نصب می‌کنید و Agent بایت‌های ESC/POS را از طریق همان صف ویندوز می‌فرستد. این روش:

- به WinUSB یا تعویض درایور نیاز ندارد (ابزار کارخانه‌ای و سایر نرم‌افزارهای صندوق سالم می‌مانند).
- روی **ویندوز ۷ و ویندوز 10/11** یکسان کار می‌کند.

روی **لینوکس و مک**، USB مستقیم با libusb انجام می‌شود (روی لینوکس با مجوز udev).

Agent قدیمی (Legacy) روی «ویندوز ۷ SP1 و جدیدتر» اجرا می‌شود؛ پس روی ویندوز modern هم می‌توانید همان مسیر بدون‑WinUSB را داشته باشید.

| سیستم        | مکانیزم USB                                  | کجا                                |
| ------------ | -------------------------------------------- | ---------------------------------- |
| ویندوز ۷     | اسپولر RAW (درایور خود پرینتر)               | Agent قدیمی (Legacy)               |
| ویندوز 10/11 | اسپولر RAW بدون WinUSB، یا USB مستقیم libusb | Agent قدیمی (Legacy) یا Agent مدرن |
| لینوکس       | USB مستقیم libusb + مجوز udev                | Agent مدرن                         |
| مک           | USB مستقیم libusb + دسترسی USB/Keychain      | Agent مدرن                         |

## ویندوز ۷ (Agent قدیمی / Legacy)

1. پرینتر USB را وصل کنید و درایور کارخانه‌ای آن را نصب کنید (تست چاپ خود ویندوز باید کار کند).
2. Agent قدیمی را باز کنید → نوع اتصال را روی «صف ویندوز (RAW)» بگذارید → «جستجوی پرینترهای ویندوز» → صف پرینتر خود را انتخاب کنید.
3. نام، کاغذ/عرض نقطه، نقش → «ذخیرهٔ تنظیمات» → «چاپ آزمایشی».

IP وارد نمی‌کنید؛ پرینتر USB از طریق صف ویندوز چاپ می‌شود.

## ویندوز 10/11

دو گزینه:

- **Agent قدیمی (Legacy) روی ویندوز modern:** برای همان مسیر بدون‑WinUSB، Legacy را نصب و دقیقاً مثل ویندوز ۷ از «صف ویندوز (RAW)» استفاده کنید. این ساده‌ترین و کم‌ریسک‌ترین راه است.
- **Agent مدرن + USB مستقیم:** اگر مدل پرینتر با درایور WinUSB سازگار است کار می‌کند؛ وگرنه باید درایور را به WinUSB عوض کنید که می‌تواند ابزار کارخانه‌ای یا سایر نرم‌افزارها را خراب کند. LAN/TCP نیز در Agent مدرن موجود است اگر ترجیح می‌دهید.

## لینوکس

USB مستقیم با libusb. یک‌بار مجوز udev را طبق [`linux.md`](linux.md) تنظیم کنید (اسکریپت کمکی)، بعد در Agent مدرن «جستجوی USB» → انتخاب دستگاه → «چاپ آزمایشی».

## مک

USB مستقیم با libusb. Agent را از DMG به Applications منتقل کنید؛ دسترسی USB/Keychain را تأیید کنید → «جستجوی USB» → انتخاب → «چاپ آزمایشی». جزئیات در [`macos.md`](macos.md).

## پیدا کردن IP پرینترهای LAN (بدون cmd/PowerShell)

اگر پرینترها با کابل لن به روتر وصل هستند، لازم نیست با `cmd`/`arp`، PowerShell یا پنل روتر دنبال IP بگردید. Agent مدرن subnet محلی را روی پورت ۹۱۰۰ اسکن می‌کند و فهرست کاندیدها را به اپلیکیشن می‌دهد:

- وب‌اپ: `printerAgent.discoverNetwork()` را صدا بزنید → `[{ host, port }]` (تا ۴ پرینتر یا بیشتر، هر کدام یک پروفایل).
- افزودن مستقیم از وب‌اپ: برای هر کاندید، `printerAgent.savePrinter({ id, name, connection: { type: "network", host, port }, paperMm, widthDots, copies, cut, fontFamily: "Noto Sans Arabic", fontSize })` — نیازی به رفتن به تنظیمات Agent نیست.
- هر کاندید را با «چاپ آزمایشی» تأیید کنید؛ «قابل اتصال» یعنی «چاپ شد» نیست.
- Agent قدیمی (Legacy) به‌جای اسکن، صف‌های نصب‌شدهٔ ویندوز را نشان می‌دهد.

## شرط درایور (ویندوز)

درایور باید ESC/POS را **بدون تغییر** به پرینتر بگذراند. درایورهای «XPS» یا «host‑based‑only» معمولاً بایت‌های RAW را دستکاری می‌کنند و نامناسب‌اند. اگر خروجی به‌هم‌ریخته بود، به یک درایور Generic/Text یا درایور سازگار با ESC/POS سوییچ کنید و دوباره «چاپ آزمایشی» بزنید.

«ارسال شد» یعنی بایت‌ها به ترانسپورت تحویل شد (برای اسپولر: به ویندوز؛ برای LAN: پذیرش TCP)، نه تأیید چاپ روی کاغذ. کاغذ را بررسی کنید؛ نتیجهٔ نامشخص را قبل از چاپ مجدد بازبینی کنید.

## WebUSB چرا در این راه نیست

WebUSB یک API مرورگر است و روی مرورگرهای قدیمی ویندوز ۷ کار نمی‌کند. Agent بومی این محدودیت را دور می‌زند و **نیازی به تغییر کد WebUSB سایت نیست**؛ SDK می‌تواند تابع WebUSB موجود را بدون تغییر به‌عنوان fallback تزریق کند (جزئیات در [`connection-compatibility-fa.md`](connection-compatibility-fa.md) و [`integration.md`](integration.md)).

## وضعیت و گام بعدی

- چاپ USB روی همهٔ نسخه‌ها امروز امکان‌پذیر است: ویندوز از طریق اسپولر RAW، لینوکس/مک از طریق libusb.
- بهبود آیندهٔ اختیاری: افزودن ترانسپورت «اسپولر RAW ویندوز» به Agent مدرن (Rust) تا ویندوز modern بدون WinUSB‑swap در یک برنامه پوشیده شود. این تغییر باید روی CI ویندوز + سخت‌افزار واقعی build و تأیید شود و هنوز پیاده نشده است.
