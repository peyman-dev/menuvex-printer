# Troubleshooting

Start with native **بررسی اتصال** and **چاپ آزمایشی**, independent of the PWA. If bytes are sent but no correct paper appears, inspect hardware/firmware/profile before changing PWA code.

| Symptom / code                                                    | Action                                                                                                                                                                                                          |
| ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AGENT_UNAVAILABLE` in SDK                                        | Check tray process, exact port, browser console CSP/mixed-content/local-network policy, firewall. Unavailable does not prove not installed.                                                                     |
| `PORT_IN_USE_OR_UNAVAILABLE`                                      | Choose a different high port in Agent Settings, Restart via tray, configure same SDK port. Never bind LAN as a workaround.                                                                                      |
| `SECURE_STORAGE_UNAVAILABLE`                                      | Unlock Keychain/Secret Service; run in the normal user's graphical login. No plaintext/root workaround. Startup currently fails closed and logs/reports failure, rather than running an unauthenticated bridge. |
| `PAIRING_REQUIRED`, `AUTH_FAILED`                                 | Pair from official HTTPS origin. Rotation/site-data clearing/new browser profile requires pairing again. Check exact apex/www origin.                                                                           |
| `PROTOCOL_VERSION`, `INVALID_PAYLOAD`                             | Match v1 SDK and request schemas; remove unknown fields, raw bytes and invalid IDs.                                                                                                                             |
| `PRINTER_NOT_FOUND`                                               | Configure printer locally; refresh list/routes. Saved IDs should not be invented by PWA.                                                                                                                        |
| `USB_ACCESS_DENIED`                                               | Linux exact udev rule + replug; Windows approved compatible driver; macOS ownership check. Do not run Agent as root.                                                                                            |
| `USB_BUSY`, `USB_DEVICE_ERROR`                                    | Close vendor spooler/WebUSB/other process using same interface. Verify class/alternate/endpoint and supported driver.                                                                                           |
| `USB_AMBIGUOUS`                                                   | Duplicate serial/identity. Use correct printer/topology; do not choose the first matching VID/PID silently.                                                                                                     |
| `PRINTER_OFFLINE`, `NETWORK_CONNECTION_FAILED`, `NETWORK_TIMEOUT` | Power, cable, DHCP reservation, private IP and port. Pre-send failures retry up to configured limit.                                                                                                            |
| `FONT_UNAVAILABLE`, `FONT_GLYPH_MISSING`                          | Use bundled Noto Sans Arabic profile; remove unsupported emoji or choose a verified local font with glyph coverage.                                                                                             |
| `ESC_POS_ERROR`, `INVALID_JOB`                                    | Check semantic limits, dot width, length and paper model. Split oversized documents using stable part IDs.                                                                                                      |
| `PRINT_OUTCOME_UNKNOWN`                                           | STOP automatic replay. Inspect the paper and order status. If reprint truly necessary, operator creates a new explicitly audited job ID.                                                                        |
| `JOB_ID_CONFLICT`                                                 | Same ID used for different printer/document. Fix business adapter/ownership; do not bypass with random IDs.                                                                                                     |
| `QUEUE_FULL`, `QUEUE_ERROR`                                       | Resolve active jobs, check disk space/permissions and integrity. Stop Agent before offline DB maintenance/backup. Never delete dedup rows to force retry.                                                       |
| Cutter or Persian clipping                                        | Correct dots/font size/cut setting; verify GS v 0 support and physical width. Successful transport is not output verification.                                                                                  |

Logs use Tauri's OS log directory, daily rotation, at most seven files. DB uses Tauri app data directory `ir.menuvex.printer/agent.sqlite3`; exact base differs per OS (AppData on Windows, Application Support on macOS, XDG data on Linux). Avoid posting raw DB: it contains receipt data. Debug from a terminal if startup fails before UI, e.g. `npm run tauri -- dev` on a configured developer machine. Production log level is INFO; traces deliberately exclude secrets, complete orders and device serials.

For a backup, Quit gracefully and copy the entire data directory only after process exits (including WAL if any); don't copy only a live SQLite main file. Restoring an older DB can lose dedup tombstones and cause replay: disable automatic print and reconcile against backend job ownership before resuming.
