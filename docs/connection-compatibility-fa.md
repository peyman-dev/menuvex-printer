# اتصال سایت به Legacy و نسخهٔ جدید

Legacy حذف نشده است. کد آن در `legacy-windows/` است و ساخت Windows، نصب‌کننده‌های x86/x64 را در `Legacy-Windows7/` داخل artifact ویندوز قرار می‌دهد. نام بیرونی artifact همچنان `MenuVex-Installer-Windows-x64` است؛ نصب‌کنندهٔ ریشهٔ آن نسخهٔ جدید است، نه Legacy.

## قرارداد مشترک

| نوع پروتکل | کاربرد                  | فیلدهای اتصال                        |
| ---------- | ----------------------- | ------------------------------------ |
| `usb`      | USB مستقیم نسخهٔ جدید   | شناسه‌ها و interface/endpoint دستگاه |
| `network`  | شبکهٔ مستقیم نسخهٔ جدید | `host`, `port`                       |
| `spooler`  | صف چاپ ویندوز در Legacy | `queueName`                          |

`lan` نام نوع اتصال در این پروتکل نیست؛ می‌تواند فقط عنوان نمایشی سایت باشد. وجود نوع spooler در SDK به معنی پیاده‌سازی آن در موتور Rust نسخهٔ جدید نیست. Legacy صف‌های ویندوز را پشتیبانی می‌کند، نه تنظیم USB مستقیم/host دلخواه.

## رفع خطای connection.type در سایت

1. کل پوشهٔ `sdk/src` همین revision را با حفظ مسیر importها در پروژهٔ سایت همگام کنید؛ اگر از hookهای این مخزن استفاده می‌کنید، `sdk/react` را هم همگام کنید. فقط تغییر فایل نصب کافی نیست.
2. schemaهای محلی سایت را پیدا کنید: `connection`, `discriminatedUnion`, `lan`, `usb`, `spooler`. خروجی Agent را با union قدیمی `[lan, usb]` دوباره اعتبارسنجی نکنید. از `connectionSchema` و `printerSchema` SDK مشترک استفاده کنید.
3. در نمایش نام اتصال، `spooler` را با `queueName`، `network` را با `host:port` و `usb` را با شناسهٔ USB نمایش دهید. نوع spooler را به usb تغییر ندهید.
4. پروفایل اتصال از فهرست Agent می‌آید؛ سایت برای چاپ همان `printerId` را با سند معنایی می‌فرستد. شبکه یا مسیر فایل دلخواه به فرمان چاپ اضافه نکنید.
5. سایت را build/deploy کنید و نسخهٔ کش‌شدهٔ سایت را به‌روزرسانی کنید. فقط یک Agent روی پورت انتخاب‌شده اجرا شود. Legacy کلید و تاریخچهٔ جدا دارد؛ کارهای قبلی را خودکار به آن منتقل نکنید.
6. ابتدا دریافت فهرست XP-80C و اتصال `spooler`، سپس یک چاپ آزمایشی کنترل‌شده را تأیید کنید. خطای schema با خطای ارسال واقعی چاپ متفاوت است.

تست‌های `sdk/tests/client.test.ts` دریافت هر سه نوع اتصال از مسیر SDK احراز هویت‌شده را بررسی می‌کنند. دادهٔ نامعتبر همچنان رد می‌شود؛ SDK جدید برای خطای اتصال، `CONNECTION_SCHEMA_MISMATCH` قابل‌فهم می‌دهد، نه توصیهٔ تعویض درایور. یک schema قدیمی در پروژهٔ دیگری با تغییر این مخزن خودکار اصلاح نمی‌شود.

## ظاهر و زبان

Legacy یک برنامهٔ بومی Win32 است، نه WebView. کنترل‌ها و منوی کنار ساعت فارسی شده‌اند و رنگ سبز، زمینهٔ روشن و قلم مناسب فارسی به آن اضافه شده است. ورودی‌های فنی مانند پورت و کلید اتصال عمداً چپ‌به‌راست هستند. این تغییر، بازسازی کامل رابط React یا افزودن WebView2 نیست. منوی کنار ساعت نسخهٔ جدید هم فارسی است؛ عنوان استاندارد Minimize/Maximize سیستم‌عامل را زبان خود سیستم تعیین می‌کند.

ساخت موفق، تأیید چاپ واقعی یا سازگاری کامل Win7 نیست. نصب‌کننده‌های قبلی این تغییرات را خودکار دریافت نمی‌کنند.
