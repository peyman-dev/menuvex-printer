# «Local Agent نمی‌تواند وصل شود» — عیب‌یابی (ویندوز ۷ و بقیهٔ سیستم‌ها)

## این پیام یعنی چه؟

مرورگر نتوانسته اتصال `ws://127.0.0.1:8765` را باز کند (SDK: `AGENT_UNAVAILABLE` — «Cannot reach the local agent»).
مرورگر عمداً دلیل را به سایت نمی‌گوید، پس **این یک پیام برای هر سه حالت زیر یکسان است**:

1. **Agent گوش نمی‌دهد:** اجرا نیست، بسته شده، یا پورت ۸۷۶۵ را برنامهٔ دیگری گرفته است.
2. **Agent روشن است ولی اتصال را رد کرد (HTTP 403):** آدرس صفحه (Origin) مجاز نیست، یا Host/مسیر اشتباه است.
3. **مرورگر/سایت جلوی اتصال را گرفته:** CSP سایت (`connect-src`)، مجوز «Local Network / Apps on device» در Chrome/Edge جدید، پراکسی یا آنتی‌ویروس.

کلید جفت‌سازی دلیل این خطا **نیست**: کلید اشتباه خطای دیگری می‌دهد (`AUTH_FAILED` / `INVALID_PAIRING_SECRET`) و آن هم بعد از برقراری اتصال است.

## سه بررسی سریع (حدود دو دقیقه)

**۱) پنجرهٔ Agent Legacy.** در نوار عنوان (نسخه‌های ساخته‌شده پس از این تغییر) باید نوشته باشد `… | 127.0.0.1:8765 آماده`؛ در نسخهٔ قدیمی‌تر خط وضعیت بالای پنجره باید «برنامه آماده است» باشد. اگر نوشته `اتصال سایت غیرفعال`، خط وضعیت بالای پنجره دلیل را می‌گوید (معمولاً پورت اشغال است: Agent دیگر یا برنامهٔ دیگر را ببندید و برنامه را دوباره اجرا کنید).
اگر اتصال یک سایت رد شود، همان خط وضعیت آدرس ردشده را نشان می‌دهد؛ مثلاً `آدرس سایت «https://panel.example» مجاز نیست`.

**۲) در همان مرورگر** آدرس `http://127.0.0.1:8765` را باز کنید:

- «refused to connect» / `ERR_CONNECTION_REFUSED` ⇒ Agent روی این پورت گوش نمی‌دهد (حالت ۱).
- صفحهٔ خالی، خطای ۴۲۶ یا «didn't send any data» ⇒ Agent گوش می‌دهد؛ مشکل رد شدن اتصال یا سیاست مرورگر است (حالت ۲ یا ۳).
- «در حال بارگذاری» که تمام نمی‌شود ⇒ اتصال TCP پذیرفته می‌شود ولی پاسخی نمی‌آید؛ معمولاً آنتی‌ویروس/فایروال یا نرم‌افزار ضدفیلتر/VPN قدیمی (Winsock LSP) وسط راه است (حالت ۳).

**۳) دلیل دقیق را خود مرورگر می‌گوید.** با `F12` تب **Console** را باز کنید، دکمهٔ Pair را بزنید و خط قرمز را بخوانید:

| پیام در Console                                                   | معنی                                                                                                                                                         |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `net::ERR_CONNECTION_REFUSED`                                     | حالت ۱: چیزی روی پورت گوش نمی‌دهد.                                                                                                                           |
| `Error during WebSocket handshake: Unexpected response code: 403` | حالت ۲: Agent روشن است و رد کرد؛ آدرس صفحه باید دقیقاً `https://menuvex.ir` یا `https://www.menuvex.ir` باشد (نه `http`، نه زیردامنه/پیش‌نمایش/`localhost`). |
| `Refused to connect … Content Security Policy … connect-src`      | حالت ۳: CSP سایت؛ `ws://127.0.0.1:8765` باید در `connect-src` مجاز شود.                                                                                      |
| `Mixed Content … insecure WebSocket endpoint`                     | حالت ۳: مرورگر خیلی قدیمی است؛ نسخهٔ جدیدتر نصب کنید.                                                                                                        |
| درخواست مجوز «Local network access / Apps on device»              | حالت ۳: Chrome/Edge جدید؛ برای سایت منووکس **Allow** کنید.                                                                                                   |

راه حل‌ها را با غیرفعال کردن محافظت‌های مرورگر یا ویندوز انجام ندهید.

## نکات مخصوص ویندوز ۷

- فقط نصب‌کنندهٔ Legacy (`MenuVex-Printer-Agent-Legacy-1.0.0-windows7-x86|x64-setup.exe`) روی ویندوز ۷ کار می‌کند؛ `setup.exe` اصلی برای ویندوز ۱۰ به بالا است.
- آیکون کنار ساعت در ویندوز ۷ ممکن است پشت پیکان «Show hidden icons» باشد. اگر آیکون نیست، پنجرهٔ برنامه را بررسی کنید.
- پورت را با `netstat -ano | findstr :8765` ببینید؛ باید `127.0.0.1:8765 … LISTENING` باشد.
- آنتی‌ویروس/فایروال ثالث، پراکسی یا VPN سیستمی می‌توانند اتصال محلی را ببندند؛ برنامهٔ منووکس را در آن‌ها مجاز کنید.
- Agent مدرن و Legacy هر دو پورت ۸۷۶۵ را می‌خواهند؛ فقط یکی را اجرا کنید.
- مرورگر باید آن‌قدر جدید باشد که سایت منووکس را اجرا کند (`crypto.subtle`، IndexedDB و WebSocket).

## گزارش Agent Legacy

فایل `%LOCALAPPDATA%\MenuVexPrinterLegacy\agent.log` فقط **کد** ثبت می‌کند، نه کلید و نه محتوای رسید:

| کد                                  | معنی                                                                      |
| ----------------------------------- | ------------------------------------------------------------------------- |
| `PORT_IN_USE_OR_UNAVAILABLE`        | پورت اشغال است؛ Agent گوش نمی‌دهد.                                        |
| `ORIGIN_NOT_ALLOWED`                | آدرس صفحه مجاز نیست (فقط دو آدرس رسمی منووکس).                            |
| `HOST_MISMATCH`, `PATH_NOT_ALLOWED` | آدرس اتصال باید دقیقاً `ws://127.0.0.1:<پورت>/` باشد.                     |
| `TOO_MANY_CONNECTIONS`              | بیش از ۸ اتصال باز؛ تب‌های اضافی را ببندید.                               |
| `SERVER_STOPPED`                    | سرویس شبکهٔ برنامه ناگهانی متوقف شد؛ برنامه را دوباره اجرا کنید.          |
| `TRAY_RETRY`                        | آیکون کنار ساعت هنگام ورود ساخته نشد؛ برنامه ادامه می‌دهد و تکرار می‌کند. |

آدرس ردشده فقط در پنجرهٔ برنامه (در حافظه) نمایش داده می‌شود و در فایل ثبت نمی‌شود.
