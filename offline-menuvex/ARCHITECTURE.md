# معماری سامانه جامع دسکتاپ کافیش (Coffish Standalone Offline Desktop Architecture)

`desktop/` یک برنامه دسکتاپ کامل، مستقل و آفلاین‌محور (**Standalone Production Offline Desktop Application**) برای سیستم‌عامل‌های **Windows (`.exe`)، macOS (`.app` و باینری) و Linux** است که تمامی ۱۱ حوزه عملیاتی بک‌اند FastAPI کافیش را به‌صورت بومی و بدون نیاز به اینترنت یا سرور خارجی روی رایانه کافه اجرا می‌کند.

## مرز اجرایی و معماری سیستم (Runtime Boundary)

```text
پنجره بومی دسکتاپ (Windows .exe / macOS .app / Linux Binary)
     │ درخواست‌های محلی HTMX و REST (Loopback / Wails AssetServer)
     ▼
هسته گولنگ دسکتاپ کافیش (desktop.Application + /local/* + /api/v1/*)
     │ تراکنش‌های اتمیک ACID با قفل انحصاری و نوشتن ایمن (0600)
     ▼
موتور ذخیره‌سازی تراکنشی محلی گولنگ خالص (CGO_ENABLED=0) روی دیسک رایانه
```

- **بدون وابستگی به کامپایلر C (`CGO_ENABLED=0`)**: موتور ذخیره‌سازی در `desktop/internal/store` به‌طور کامل با کتابخانه استاندارد Go پیاده‌سازی شده است تا کامپایل متقابل (Cross-Compilation) برای ویندوز (`.exe`)، مک و لینوکس از روی هر سیستم‌عاملی بدون نیاز به CGO انجام شود.
- **تراکنش‌های ACID محلی**: هر تغییر در پایگاه داده محلی روی یک کپی تراکنشی اعمال شده، در فایل موقت `.tmp` نوشته و `fsync` می‌شود و سپس به‌صورت اتمیک جایگزین فایل اصلی می‌گردد. در صورت بروز هرگونه خطا، کل تراکنش به حالت قبل بازمی‌گردد (Rollback).

## پوشش کامل ۱۱ ماژول عملیاتی بک‌اند (۷۴۸ نقطه پایانی)

| ماژول دسکتاپ | قابلیت‌های پیاده‌سازی‌شده در موتور محلی دسکتاپ |
|---|---|
| ۱. صندوق فروش، سفارش‌ها و تقسیم دنگ (`pos_orders_splitbill`) | ثبت سفارش سالن/بیرون‌بر/پیک، محاسبه دقیق ریال و تومان، تخفیف، تسویه کارتخوان/نقدی/نسیه، **ماشین‌حساب دنگ (Split Bill)** و بستن صندوق روزانه (`Z-Report`) |
| ۲. چاپگرهای حرارتی ۸۰ میلی‌متری و مسیردهی چاپ (`thermal_printers_routing`) | پیش‌نمایش و چاپ مستقیم **فیش تسویه مشتری** و **حواله آماده‌سازی بار (فیش باریستا)** در ابعاد استاندارد ۸۰ میلی‌متری + قوانین مسیردهی دسته‌بندی به چاپگر |
| ۳. منو، دسته‌بندی‌ها، محصولات و افزودنی‌ها (`menu_catalog_modifiers`) | مدیریت کامل محصولات، دسته‌بندی‌ها، **گروه‌های افزودنی (Modifier Groups)** و بنرهای دیجیتال |
| ۴. انبارداری، رسپی (BOM)، تامین‌کنندگان و خرید (`inventory_suppliers_bom`) | ثبت اسناد ورود خرید، مصرف، ضایعات و تعدیل انبارگردانی، **کسر خودکار مواد اولیه بر اساس رسپی هنگام تکمیل سفارش**، پرونده تامین‌کنندگان، فاکتورهای خرید و برگه‌های شمارش فیزیکی |
| ۵. سالن، میزها و رزرواسیون (`tables_floor_reservations`) | نقشه وضعیت میزها (`آزاد`، `اشغال`، `رزرو شده`)، اشغال/آزادسازی خودکار میز با سفارش و تقویم رزرو مهمانان |
| ۶. باشگاه مشتریان، وفاداری و بازگشت مشتری (`customers_loyalty_retention`) | پرونده مشتریان، محاسبه خودکار امتیاز وفاداری، **کمپین‌های بازگشت مشتری (Retention)** و **پلن‌های اشتراک ماهانه قهوه** |
| ۷. دفتر نسیه و حساب‌های دفتری (`debtors_credit_ledger`) | ثبت خودکار یا دستی بدهکاران، پیگیری مانده بدهی و ثبت تسویه اقساطی یا کامل |
| ۸. حسابداری دوبل، هزینه‌ها و تحلیل عمیق (`accounting_finance_analytics`) | ثبت هزینه‌های جاری، **دفتر روزنامه حسابداری دوبل**، تراز فروش نقدی/کارتخوان/نسیه و سود خالص عملیاتی |
| ۹. پرسنل، شیفت، چک‌لیست و استخدام (`staff_shifts_jobs`) | پرونده پرسنل و حقوق، چک‌لیست اجرایی روزانه باریستا و **آگهی‌های استخدام و کاریابی کافه** |
| ۱۰. تنظیمات کافه، ساعات کاری و پشتیبان‌گیری (`cafe_profile_settings`) | مشخصات کافه روی فیش، ساعات کاری و دریافت خروجی پشتیبان JSON (`GET /backup.json`) |
| ۱۱. هسته محلی REST و حاکمیت داده (`local_system_governance`) | ارائه مستقیم نقاط پایانی `/api/v1/*`، `/health` و `/ready` روی سیستم محلی به همراه محافظت CSRF و Host Allowlist |

## استانداردهای بومی و انسانی رابط کاربری ایرانی (Iranian Standard UI)

- **چینش راست‌به‌چپ (`dir="rtl" lang="fa"`) و تایپوگرافی استاندارد فارسی** (`Vazirmatn`, `IRANSansX`, `YekanBakh`).
- **تقویم هجری شمسی (`desktop/jalali.go`)**: تبدیل دقیق تاریخ و زمان به وقت تهران (`Asia/Tehran`) و نمایش به فرمت شمسی (`یکشنبه ۲۶ مهر ۱۴۰۵`).
- **محاسبات مالی دقیق ریال و تومان**: استفاده از `math/big` برای تبدیل بدون خطای ریال به تومان با ارقام فارسی و جداکننده هزارگان (`۱۴۵٬۰۰۰ تومان`).
