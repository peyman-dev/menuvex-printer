# ماتریس تطبیق MenuVex Offline (Coffish) ↔ MenuVex Web

مرجع قطعی: سورس وب همین ریپو (`app/dashboard/**`, `components/templates/dashboard/**`, `public/css/globals.css`).
وضعیت‌ها: ✅ همسان/کارا — 🟡 جزئی (هست ولی اختلاف دارد) — ❌ غایب — ⚪ ذاتاً آنلاین/نامرتبط با آفلاین.
«صحت‌سنجی» یعنی چطور بررسی شد: T=تست خودکار، L=بررسی زنده روی پیش‌نمایش، S=مقایسه سورس، U=تأیید کاربر با اسکرین‌شات (در سندباکس مرورگر headless نیست).

### ردیف سفارش‌ها — استانداردسازی (شکایت کاربر: ردیف بزرگ و هم‌پوشانی بج روی دکمه‌ها)

### برگه شمارش انبارگردانی — حذف صفحه بدون معادل وب و تراز مسیر شمارش
- ✅ علت پیدا نشدن در وب روشن و اصلاح شد: وب‌اپ صفحه یا لینک جدا برای «برگه شمارش انبارگردانی» ندارد؛ شمارش از مدیریت انبار و دیالوگ «ثبت تغییر موجودی» روی قلم انجام می‌شود. صفحه قدیمی `?page=drafts` که شمارش آزاد را جدا از موجودی نگه می‌داشت، از سایدبار، قالب، route و handler حذف شد و `GET /?page=drafts` پاسخ 404 می‌دهد.
